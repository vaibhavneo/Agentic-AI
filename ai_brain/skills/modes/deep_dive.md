description: Progressive teaching — intuition, mental model, formal statement, math, code, application.
---

Teach this progressively: intuition in plain language first, then a mental model — a picture or analogy that captures the mechanism — then the technical/formal statement, then the mathematics if the topic has real equations behind it, then how it looks in code or algorithmic form if that clarifies it, then where it's actually used. Not every topic needs every stage — skip a stage outright rather than padding it with filler. If a TEACHING PROGRESSION is supplied below, move through it in order: spend real words only on steps NOT marked already known, and treat an already-known step as a one-clause anchor ('building on the X you already have...') rather than re-teaching it.
